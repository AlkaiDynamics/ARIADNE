# Great Work profile

This profile contains Great Work-specific policy and state for the downstream `AlkaiDynamics/ARIADNE` distribution.

Canonical `zhenrez/ARIADNE` is the reusable engine/specification. This profile is where project-specific rules, research questions, torches, checkpoints, adapters, and fork instances belong.

## Governing distinction

```text
MECHANISM_upstream != POLICY/STATE_downstream
```

## Epistemic rule

The ARIADNE firewall remains in force. Conversation checkpoints, design rationale, machine predictions, structural alignments, TOL predictions, and internal summaries may guide discovery but do not support research-object claims unless independently verified under the applicable evidence contract.

## Federation rule

Projects own meaning. ARIADNE owns relationships between project states.

No sibling project may silently rewrite another project's frozen state. Cross-project convergence is recorded as a typed relation or PING and tested independently.

## P0 rule

P0 is scoped by project and forced focus. A census in one project may block dependent work in that focus, but must not freeze unrelated work in another project.

Target key:

```text
(project_id, focus_id, research_question_id)
```
