# Great Work Profile

This directory is downstream-owned configuration/policy territory for the Alkai Great Work distribution.

The profile exists to keep project-specific policy and vocabulary out of the canonical ARIADNE engine while preserving a clean place for federation-wide behavior shared by AYLI, SUN, SATURN, Sophia, Argo/Lifeline, Harmonia-Occulta, R.O.S.E.T.T.A.S., and later projects.

## Intended contents

- Great Work checkpoint cadence and continuity policy instances;
- project registration and aliases;
- project-scoped validation regimes;
- downstream provenance vocabulary extensions;
- project/focus-scoped P0 defaults;
- adapter configuration;
- presentation/view preferences that do not alter evidence semantics.

## Non-goals

Do not move active runtime configuration here until ARIADNE can resolve profile-owned paths without breaking existing behavior.

Do not place primary research evidence here merely because it belongs to the Great Work. Evidence should remain in its owning research object/workspace and be referenced through ARIADNE custody/provenance records.
