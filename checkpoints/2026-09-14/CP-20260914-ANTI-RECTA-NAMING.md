# ARIADNE Conversation Checkpoint — Naming Lock

## Decisions and new rules

The naming motion was seconded and explicitly **LOCKED**.

Canonical names:

- **ANTI-RECTA** — the full cross-tradition discrepancy/alignment architecture; the space in which systematic non-alignment, omission, substitution, transposition, phonetic drift, lineage conflict, count mismatch, and related discrepancies are preserved and compared so that hidden transformation rules can be reconstructed.
- **KASISKI** — the recurrence detector / hidden-periodicity search operating over ANTI-RECTA; used to identify repeated structures, spacings, motifs, discrepancy classes, and latent architecture across separated corpora or traditions.
- **VOID GRID** — the unresolved / missing-address projection within ANTI-RECTA; used for missing, contradictory, damaged, unfilled, or unknown cells/addresses and for predicting the feature-shape of what should occupy them.
- **BEAUFORT** — the reciprocal / inverse-transform operator; reserved for cases where an outward transform and its return/inverse share the same or closely related structural form.

Relationship:

```text
ANTI-RECTA
 ├── KASISKI      = recurrence / hidden-structure detector
 ├── VOID GRID    = missing / unresolved address projection
 └── BEAUFORT     = reciprocal / inverse-transform operator
```

Formal shorthand:

```math
\text{ANTI-RECTA}:\quad A_i \not\cong B_i \Rightarrow \text{infer the transformation explaining the discrepancy}
```

```math
\text{KASISKI}:\quad \{r_1,r_2,\ldots,r_n\}\rightarrow\widehat{P}\;\text{(latent recurrence / periodic architecture)}
```

```math
\text{VOID GRID}:\quad u_{i-1},\;?,\;u_{i+1}\rightarrow\widehat{\Phi}(u_i)
```

```math
\text{BEAUFORT}:\quad T^{-1}\sim T
```

## Corrections and superseded states

- The proposed **CTRM / Cross-Tradition Representation Matrix** naming is rejected and superseded by **ANTI-RECTA**.
- The earlier suggestion to use “Rosetta Matrix” as the technical name for this architecture is rejected for this purpose.
- This checkpoint records only the locked ANTI-RECTA / KASISKI / VOID GRID / BEAUFORT convention; it does not resolve every other historical or repository use of the word “Rosetta.”

## Equation / schema / transform / mapping changes

The architecture is now treated as a system rather than a single table:

1. **ANTI-RECTA** preserves the complete discrepancy/alignment space.
2. **KASISKI** searches it for recurrence, periodicity, and hidden shared structure.
3. **VOID GRID** isolates unresolved or missing addresses and supports search-prior generation.
4. **BEAUFORT** handles reciprocal/inverse transforms when applicable.
